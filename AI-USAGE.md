# AI Usage

This project was developed with the assistance of Gemini as a coding and development support tool.

Areas Where AI Assistance Was Used

- Assisted with implementing regex-based parsing of the Markdown policy document into distinct clauses.
- Assisted with implementing the local semantic-search retrieval pipeline using sentence-transformers.
- Assisted with generating evaluation prompts and constructing test cases based on the provided policy manual.
- Assisted with preparing project boilerplate and configuration files such as requirements.txt and .gitignore.
- Assisted with architectural updates, including temporal policy versioning, natural-language date extraction, and documentation   of design trade-offs.
- AI was used as a development aid for coding, testing, and documentation. The overall project design, implementation decisions, integration, and validation were carried out as part of the project development process.
