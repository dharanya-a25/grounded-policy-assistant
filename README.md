# The Grounded Answer

Brite Spark 2026 — AI / RAG

A grounded policy assistant that answers questions using the provided policy manual and amendment, cites the exact policy clause used, and refuses to guess when the policy does not provide enough information.

## Features

- Grounded answers from the policy manual
- Clause-level citations
- Refusal for unsupported questions
- Contradiction detection
- Date-sensitive policy handling
- Support for the Day 2 amendment
- CLI-based interface
